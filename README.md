# Ultrawide Wallpapers

A collection of ultrawide wallpapers. My aim here is to create a decent collection of wallpapers for ultrawide monitors, so feel free to contribute.

**[Browse the gallery](https://markpendlebury.github.io/ultrawide-wallpapers/)**

Wallpapers are organised into folders by resolution (e.g. `3440x1440/`, `5120x1440/`), with a WebP thumbnail for each under `docs/thumbs/`. The gallery is the easiest way to preview and download them.

## Contributing

Submit a pull request adding your wallpaper to the matching resolution folder (name it `<title>_<width>x<height>.<ext>`). Credit goes to the original authors where available.
